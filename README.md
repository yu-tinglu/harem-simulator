# 後宮模擬器 harem-simulator

單檔 HTML 的宮廷經營模擬遊戲：用瀏覽器開啟 `index.html` 即可遊玩，進度存於瀏覽器本機。

## 主要內容

- **出身**：選秀入宮、南巡江南、和親公主（外邦）、特殊出身（宗室郡主、女官、女醫、江湖女子等），共 21 種，難度各異。
- **後宮與前朝**：依真實規模編制妃嬪與官職；派系、長期記憶（恩怨會被記住）、官職缺額與謀缺。
- **下人**：宮女太監各有特質、職務、忠誠與能力，可差遣、賞罰、提拔；忠誠過低會背叛。
- **產業**：開鋪、整頓、擴建；特殊經營（情報樓、殺手樓、青樓、賭坊；外邦公主另有嫁妝商隊、牧場）。
- **外邦公主**：母國有國力、邦誼、滲透度、皇上猜忌；可資助母國、滲透皇朝或協助防範；可能被母國策反政變，也可能母國被皇朝併吞。
- **九龍奪嫡**：皇子結黨、構陷、暗殺、廢儲、逼宮；可為兒子謀劃或帶孩子面聖。
- **私兵**：殺手樓訓練死士、牧場養馬屯駐，形成真實私兵（月餉、暴露風險），加成宮變、逼宮、內應與奪嫡；「兵力調度」可護衛、探查、遣散。
- **皇帝疑心**：看兵力、母家、聖寵、皇帝年紀與儲位；有預警、示忠、御賜護衛與分層處罰；母國猜忌另有「澄清母國往來」。
- **警示欄與回顧**：主畫面危險值警示並附處理按鈕；結局有關鍵時刻回顧與同開局重玩；姓名全域不重複。
- **財貨運用**：買官賄賂、賞賜宮人、置產投資（田莊/放貸/商隊）、行善積德（賢名）、買通消息、珍寶收藏、宮中賭局；另有名號、每局時局、人物個人劇情與天災商機事件。
- **皇帝與皇太后**：皇帝有人生線與性格，皇太后是否在世依年齡推算。
- **介面**：手機優先；頂部狀態列、行動分組收合、名冊排序篩選、大事年表、事件頻率設定。

## 開發筆記

專案為單一 `index.html`（原生 JS／CSS），遊戲狀態集中於全域 `S`；事件以 `{t, o:[[選項, 結果函式]]}` 推入 `S.q`。存檔鍵為 `shengong_slot_N`，設定鍵為 `hg_*`。
