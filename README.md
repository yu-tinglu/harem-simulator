# 後宮模擬器 harem-simulator

**目前版本：V277**（單一檔案、不再逐版記流水帳；每次更新只改這份說明與版本號）

單檔 HTML 的宮廷經營模擬遊戲：用瀏覽器開啟 `index.html` 即可遊玩，進度存於瀏覽器本機。手機與電腦皆可玩（電腦寬螢幕為左側導覽＋置中單欄版面，手機為單欄＋底部導覽）。

## 目前功能

### 開局與出身
- 25 種出身（選秀、南巡江南、和親公主、宗室郡主、女官、女醫、江湖女子、將門孤女、修行女冠、戲班班主之女等），難度與推薦標示不同；各出身有專屬開場事件、家人設定與省親（回家）方式。
- 捏人兩步：角色・出身・天賦 → 目標與入宮；入宮前有備選策略（打點、結交同屆、備考）。
- 前世傳承與多週目羈絆（上一世的摯友、宿敵會在下一世重逢）；每日挑戰；輕鬆／完整兩種玩法；成就與結局圖鑑（含跨局事件收集進度）。

### 後宮與人物
- 依真實規模編制妃嬪與官職；派系、長期記憶（恩怨與人情簿）、官職缺額與謀缺。
- 每位人物有固定性情、五層人生檔案、專屬故事（求子、母家風雲、舊案、出宮之念等）；全站人名可點開檔案。
- 內建古裝畫像作頭像（每人固定不重複，可自行上傳照片，僅存本機）；外邦公主妃嬪依邦國配專屬畫像（吐蕃、安南、高麗、準噶爾、蒙古各 4 張，暹羅暫用通用畫像）；所有頭像可點擊放大。
- 妃嬪之間自己會結盟、陷害、反咬、降位、出家；結盟者可能背叛、失勢宿敵可能求饒；倒台妃嬪有後續。
- 外邦公主妃嬪（連動邦誼）、宮中小報／後宮風向、宮外傳聞（真假混合，可花銀兩查證或利用）。
- 下人（宮女太監）有特質、職務、忠誠與能力，可差遣賞罰，忠誠過低會背叛。

### 行動與經濟
- 恩寵聖眷、人脈勢力、修身養性、子嗣、朝政等行動分類；行動有隱性代價；專長達標會解鎖專屬選項。
- 財貨：買官賄賂、賞賜、置產投資、行善積德、買通消息、珍寶收藏、宮中賭局；產業與特殊經營（情報樓、殺手樓、青樓、賭坊、嫁妝商隊、牧場）；份例與開銷公式、國庫與通膨平衡。
- 宮中走動（多處地點）、宮外世界（省親、護國寺、隨駕行宮、南巡、微服）、節令事件（春節到冬至，依位份與處境有不同版本與開場句）。
- 事件選項附穩妥／冒險／耗銀標籤；選擇有後果與伏筆，數月後會有「前事回響」。

### 皇帝、前朝與奪嫡
- 皇帝有年號、性情、心事與人生線；皇帝疑心看兵力、母家、聖寵、年紀與儲位；有預警、示忠與分層處罰。
- 時代背景（盛世、亂世、中興、外戚專權、天災頻仍）、天災大事件、朝廷官員長篇故事線。
- 九龍奪嫡：皇子結黨、派系擁立、構陷、暗殺、廢儲、逼宮；私兵（死士、屯駐）加成宮變。
- 皇子公主封爵、宗室歲俸、削藩猜忌、族譜與家族餘蔭；皇室成員、子嗣總覽與孩子詳情頁。

### 子嗣
- 親生孩子有專屬畫像（20 位人物，女 10 位、男 10 位，各有幼年／少年／青年／老年四張，隨年齡自動換階段：0–5、6–15、16–35、36 歲以上）；其他妃嬪的孩子使用「普通池」畫像（女 21～30、男 31～40，各 4 階段；目前女 21 號已有圖，其餘補圖中，抽不到的維持原頭像）；孩子有資質與特質（受母親影響）、培養方式；成長線（啟蒙、志向、成年禮、孫輩）；嬰幼兒與兒童事件依年齡出現不同選項；孕期宮鬥（下毒、驚嚇、流言、早產）、安胎與追查。

### 特殊身分
- 和親公主：母國國力、邦誼、滲透度、猜忌；可資助或被策反；喪夫後可成攝政太后。
- 皇后、太后模式：管教皇后、選人侍君、主持選秀、暗算皇后；太后期有「皇帝的後宮」名冊；臨朝與還政。
- 主角心事線（侍衛／太醫／親王）、十年宿敵、閨中密友等長篇故事。

### 自動與介面
- 「自動過一季／一年」：可選方針、遇事處理方式與目標，遇重大事件會停下；結束後有回顧卡。
- 頂部狀態列與「下一個目標」、單則通知（晉升等通知只顯示一次）、紀事與通知記錄、大事年表、關係圖。
- 版面：手機單欄；寬螢幕（≥1000px）左側直式導覽＋置中單欄（寬約 760px）。字體可調（小／中／大／特大）、深色／淺色切換、古風背景音樂與提示音。
- CG 插圖（11 張）：結局卡依結局類型配圖（登基、垂簾、冷宮、廢位、病榻、老年、母子等）；首次生子、冊封皇后、宮宴與外邦來朝事件時彈出插圖（宮宴與來朝每局最多各 3 次）。
- 結局：多種結局、一生走勢圖、十個關鍵選擇、子女成長記、史官評語、結局分享圖。
- 存檔：自動存檔＋多格手動存檔，可匯出／匯入（複製文字或檔案）；每兩年提醒備份；回報問題一鍵複製診斷文字；網址開啟時有新版本提示。

## 開發筆記

專案為單一 `index.html`（原生 JS／CSS），遊戲狀態集中於全域 `S`；事件以 `{t, o:[[選項, 結果函式]]}` 推入 `S.q`。存檔鍵為 `shengong_slot_N`，設定鍵為 `hg_*`。更新以追加修補區塊的方式進行，版本號為檔內 `VER92`。自動測試：`node tests/run-all.js`（需 playwright）。
